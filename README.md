# Summary

This repository contains tools for programmatic access to coin data from the Professional Coin Grading Service (PCGS).

## pcgs_api

Python wrapper for the PCGS Public API.

Official PCGS documentation can be found here: https://www.pcgs.com/publicapi/documentation

Swagger Docs for the API can be found here: https://api.pcgs.com/publicapi/swagger/ui/index

You are required to sign up and have a daily limit of 1,000 API calls. 

## pcgs_scraper

Tools for scraping coin data from PCGS's coin prices data at https://www.pcgs.com/prices 

For more detail see the [pcgs_scraper README](packages/pcgs_scraper/README.md)
